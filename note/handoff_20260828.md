## 2. 実装したい機能の要件

### ゴール
コンビニ店舗調査アプリ（社内）に、**2つのポップアップ機能**を jQuery ウィジェットとして組み込む。

### 機能A：調査対象店舗選択ポップアップ（`CvsStoreWidget.StoreSelect`）
- 店舗名フリー入力 → `nm_cvs_store LIKE '%入力%'` を Ajax サジェスト（`GET /api/stores/search?q=`）。
  - IME変換中は検索しない（`compositionend` で1回）。デバウンス300ms。
  - フォーカスを外して戻ると即再検索（デバウンス無し）。ただし「確定済みの選択と現在値が一致」なら再表示しない（`isResolved`）。
- チェーン名 / 立地条件 / 都道府県 は `<select>`。マスタ取得は**空JSON body の POST**（`/api/cvs_chains`, `/api/cvs_locations`, `/api/regions`）、レスポンスは `{ records:[...] }`。
- 店舗の選び方は3通り：サジェスト候補 / お気に入りチップ / 未登録店舗を手入力。
  - 既存店舗（`appliedStore` と全項目一致）→ 登録APIは呼ばず `store-selected` イベントで `id_cvs_store` を親へ返すのみ。
  - 新規店舗（1項目でも違う）→ `window.confirm` → `PUT /api/stores`（**サーバがIDを採番**）→ `store-selected`。
  - お気に入り店舗名クリック時、同名店舗が複数チェーンにあると複数候補をサジェストに出す（`suggestController.showResults`）。
- `open()` に渡す `file`（関連ファイルID/名）は新規店舗登録リクエストに乗せる。
- 二重送信ガード（`submitting` フラグ＋OKボタン `disabled`）。
- 店舗名にチェーン名は含めない前提（例：「セブンイレブン渋谷駅前店」ではなく「渋谷駅前店」）。

### 機能B：お気に入り店舗編集（`CvsStoreWidget.FavoriteEdit`）
- 店舗名テキスト入力を最大10行。各行に機能Aと同じサジェスト。
- **単独ダイアログではなく、社内アプリの既存 jQuery UI ダイアログの中に「入力欄セクション」として埋め込む**（`mount`/`load`/`save`/`reset` API）。
- 保存先は**ブラウザCookie `favoriteStores`**（店舗名のJSON配列、最大10、30日、`path=/`）。機能Aのお気に入りチップは同Cookieを読む。

### 共通仕様
- 表示は **jQuery UI `$().dialog()`**（社内アプリの既存ダイアログと同じ仕組み）。Thymeleaf フラグメントには「中身」だけを置き、タイトルバー / OK・キャンセル / 暗幕は jQuery UI が生成。
- **コンテキストパス対応**：社内アプリはサーブレットコンテキストパス配下。画面が `cvs-api-config.js` より前に `window.CvsStoreWidget.config.contextPath` をセット（Thymeleaf の `th:inline` で `@{/}` を出力）。`apiUrl()` が全APIパスに前置。モックは `''` なので従来どおり。
- 名前空間 `window.CvsStoreWidget` に集約：
  - `.config` … `{ contextPath, paths }`
  - `.util` … `{ CookieUtil, FavoritesUtil, StoreSuggest, apiUrl(path) }`
  - `.StoreSelect` … `{ open(arg), close() }`
  - `.FavoriteEdit` … `{ mount(target?,opts?), load(), save(), getValues(), reset() }`
- 結果通知は `document` のカスタムイベント：
  - `store-selected` → payload `{ id_cvs_store, nm_cvs_store, cd_cvs_chain, nm_cvs_chain, cd_cvs_location, nm_cvs_location, cd_region, nm_region, file }`（`file` は新規登録時のみ）
  - `favorites-updated` → 保存後の店舗名配列（trim・重複排除・最大10）

### スクリプト読み込み順（社内アプリ）
```
jQuery → jQuery UI(dialog含む)
→ <script th:inline> で CvsStoreWidget.config.contextPath をセット
→ cvs-api-config.js → cvs-cookie-util.js → cvs-favorites-util.js
→ cvs-store-suggest.js → cvs-store-select.js → cvs-favorite-edit.js

```

### データスキーマ（`data/stores.js`。社内本番APIの命名に準拠）
- store: `{ id_cvs_store: number, nm_cvs_store: string, cd_cvs_chain: string, nm_cvs_chain: string, cd_cvs_location: string, nm_cvs_location: string, cd_region: string, nm_region: string }`
- **コード値（`cd_*`）は文字列型**。数値変換しない。
- マスタAPIレスポンスは `{ records: [ {cd_cvs_chain,nm_cvs_chain} ... ] }` 形式。

### APIエンドポイント（`server.js` の `ROUTES`。社内では全てコンテキストパス配下）
| 用途 | メソッド | パス | body / 応答 |
|---|---|---|---|
| 店舗名サジェスト | GET | `/api/stores/search?q=` | 応答: store配列（LIKE %q%、最大20） |
| チェーン一覧 | POST | `/api/cvs_chains` | body `{}` / 応答 `{records:[...]}` |
| 立地条件一覧 | POST | `/api/cvs_locations` | body `{}` / 応答 `{records:[...]}` |
| 都道府県一覧 | POST | `/api/regions` | body `{}` / 応答 `{records:[...]}` |
| 調査対象店舗の確定登録 | PUT | `/api/stores` | body=payload / 応答 `{success:true, id_cvs_store:<採番ID>}` |

 * ウィジェットのAjax設定を一箇所に集約する。
 * jQuery の直後・他の cvs-*.js より前に読み込むこと。

window.CvsStoreWidget = window.CvsStoreWidget || {};
window.CvsStoreWidget.util = window.CvsStoreWidget.util || {};

(function (CvsStoreWidget) {
  'use strict';

  var config = CvsStoreWidget.config || (CvsStoreWidget.config = {});

  // 画面側が既に文字列でセットしていれば尊重する。未設定時のみ '' を既定にする。
  if (typeof config.contextPath !== 'string') {
    config.contextPath = '';
  }

  config.paths = {
    SUGGEST_STORES: '/api/stores/search',
    CHAINS: '/api/cvs_chains',
    LOCATIONS: '/api/cvs_locations',
    PREFECTURES: '/api/regions',
    REGISTER_TARGET_STORE: '/api/stores'
  };

  // contextPath（末尾スラッシュは除去）＋ 先頭スラッシュ付きの相対パス。
  CvsStoreWidget.util.apiUrl = function (path) {
    var ctx = (CvsStoreWidget.config && CvsStoreWidget.config.contextPath) || '';
    ctx = ctx.replace(/\/+$/, '');
    if (path.charAt(0) !== '/') {
      path = '/' + path;
    }
    return ctx + path;
  };
})(window.CvsStoreWidget);

### 3-4. `public/js/cvs/cvs-store-suggest.js`（確定）
```js
/*
 * 店舗名サジェストを任意のテキスト入力欄に付与する共通部品。
 * window.CvsStoreWidget.util.StoreSuggest。
 */
window.CvsStoreWidget = window.CvsStoreWidget || {};
window.CvsStoreWidget.util = window.CvsStoreWidget.util || {};

CvsStoreWidget.util.StoreSuggest = (function ($) {
  'use strict';

  var apiUrl = CvsStoreWidget.util.apiUrl;
  var PATHS = CvsStoreWidget.config.paths;
  var DEBOUNCE_MS = 300;

  /**
   * @param {jQuery}   options.$input
   * @param {jQuery}   options.$list
   * @param {Function} options.onSelect  function(store)
   * @param {Function} [options.onChange] function()
   * @param {Function} [options.isResolved] function():boolean  真ならフォーカスバック再表示をスキップ
   * @param {string}   [options.emptyMessage]
   * 返り値: { hide(), showResults(resultsArray) }
   */
  function attach(options) {
    var $input = options.$input;
    var $list = options.$list;
    var debounceTimer = null;
    var isComposing = false;

    $input.on('compositionstart', function () { isComposing = true; });
    $input.on('compositionend', function () { isComposing = false; triggerSearch(); });

    $input.on('input', function (e) {
      if (typeof options.onChange === 'function') { options.onChange(); }
      if (isComposing || (e.originalEvent && e.originalEvent.isComposing)) { return; }
      triggerSearch();
    });

    $input.on('focus', function () {
      var value = $.trim($input.val());
      if (!value) return;
      if (typeof options.isResolved === 'function' && options.isResolved()) { return; }
      if (debounceTimer) { clearTimeout(debounceTimer); }
      fetchSuggestions(value);
    });

    function triggerSearch() {
      var value = $.trim($input.val());
      if (debounceTimer) { clearTimeout(debounceTimer); }
      if (!value) { hide(); return; }
      debounceTimer = setTimeout(function () { fetchSuggestions(value); }, DEBOUNCE_MS);
    }

    $(document).on('click', function (e) {
      if (!$(e.target).closest($input.parent()).length) { hide(); }
    });

    function fetchSuggestions(value) {
      $.getJSON(apiUrl(PATHS.SUGGEST_STORES), { q: value }, function (results) {
        if ($.trim($input.val()) !== value) return; // 入力が変わっていたら破棄
        render(results);
      });
    }

    function render(results) {
      $list.empty();
      if (results.length === 0) {
        var emptyMessage = options.emptyMessage || '該当する店舗がありません';
        $list.append($('<li class="cvs-suggest-empty"></li>').text(emptyMessage));
        $list.show();
        return;
      }
      $.each(results, function (i, store) {
        var $item = $('<li class="cvs-suggest-item"></li>');
        $item.append($('<span class="cvs-suggest-name"></span>').text(store.nm_cvs_store));
        $item.append($('<span class="cvs-suggest-meta"></span>').text(store.nm_cvs_chain + ' / ' + store.nm_region));
        $item.on('click', function () { options.onSelect(store); hide(); });
        $list.append($item);
      });
      $list.show();
    }

    function hide() { $list.hide().empty(); }

    return { hide: hide, showResults: render };
  }

  return { attach: attach };
})(jQuery);
```

### 3-6. `public/js/cvs/cvs-favorite-edit.js`（確定・全文）
```js
/*
 * お気に入り店舗の入力欄グループ（ホストのダイアログ等にマウントして使う）
 * window.CvsStoreWidget.FavoriteEdit 公開API:
 *   mount(target, options)  target 省略時 [data-cvs-favorite-edit-rows]。options.count で行数（既定 10）。DOM ready 後1回。
 *   load()   Cookie(favoriteStores) から各入力欄を復元。ホストダイアログの dialogopen イベントで。
 *   save()   入力値を Cookie 保存 → document に 'favorites-updated' 発火 → 保存後配列を返す。既存の保存処理内で。
 *   getValues()  現在値（trim 済み配列。保存はしない）。
 *   reset()  全行のサジェスト候補を閉じる。dialogclose イベントで。
 */
window.CvsStoreWidget = window.CvsStoreWidget || {};

CvsStoreWidget.FavoriteEdit = (function ($) {
  'use strict';

  var FavoritesUtil = CvsStoreWidget.util.FavoritesUtil;
  var StoreSuggest = CvsStoreWidget.util.StoreSuggest;
  var DEFAULT_ROWS_SELECTOR = '[data-cvs-favorite-edit-rows]';

  var $container = null;
  var $inputs = [];
  var suggestControllers = [];
  var resolvedNames = [];
  var mounted = false;

  function warnNotMounted() {
    if (window.console && console.warn) {
      console.warn('[CvsStoreWidget] FavoriteEdit.mount() が先に呼ばれていません。');
    }
  }

  function mount(target, options) {
    var $target = target ? $(target) : $(DEFAULT_ROWS_SELECTOR);
    if (!$target.length) {
      if (window.console && console.warn) {
        console.warn('[CvsStoreWidget] FavoriteEdit.mount(): マウント先が見つかりません。');
      }
      return;
    }
    $container = $target.first();
    if (!$container.closest('.cvs-store-widget').length) {
      $container.addClass('cvs-store-widget');
    }
    var count = (options && options.count) || FavoritesUtil.MAX_COUNT;
    $container.empty();
    $inputs = [];
    suggestControllers = [];
    resolvedNames = [];
    for (var i = 0; i < count; i++) { addFavoriteRow(i); }
    mounted = true;
  }

  function addFavoriteRow(index) {
    var inputId = 'cvs-favorite-input-' + index;
    var $row = $('<div class="cvs-form-row cvs-favorite-edit-row"></div>');
    $row.append($('<label></label>').attr('for', inputId).text((index + 1) + '.'));
    var $wrapper = $('<div class="cvs-autocomplete-wrapper"></div>');
    var $input = $('<input type="text" autocomplete="off">')
      .attr('id', inputId).attr('placeholder', '店舗名を入力してください');
    var $list = $('<ul class="cvs-suggest-list" style="display:none;"></ul>');
    $wrapper.append($input).append($list);
    $row.append($wrapper);
    $container.append($row);
    $inputs.push($input);
    resolvedNames[index] = null;
    suggestControllers.push(StoreSuggest.attach({
      $input: $input,
      $list: $list,
      onChange: function () { resolvedNames[index] = null; },
      onSelect: function (store) { $input.val(store.nm_cvs_store); resolvedNames[index] = store.nm_cvs_store; },
      isResolved: function () {
        return resolvedNames[index] !== null && $.trim($input.val()) === resolvedNames[index];
      }
    }));
  }

  function load() {
    if (!mounted) { warnNotMounted(); return; }
    var favorites = FavoritesUtil.getNames();
    $.each($inputs, function (i, $input) {
      var name = favorites[i] || '';
      $input.val(name);
      resolvedNames[i] = name || null;
    });
  }

  function getValues() {
    return $.map($inputs, function ($input) { return $.trim($input.val()); });
  }

  function save() {
    if (!mounted) { warnNotMounted(); return []; }
    var names = $.map($inputs, function ($input) { return $input.val(); });
    var saved = FavoritesUtil.saveNames(names);
    $(document).trigger('favorites-updated', [saved]);
    return saved;
  }

  function reset() {
    $.each(suggestControllers, function (i, controller) { controller.hide(); });
  }

  return { mount: mount, load: load, save: save, getValues: getValues, reset: reset };
})(jQuery);
```
